# About This Project

Praktijk 56 is a starting massage practice. The owner will soon open her practice. 
She would like a website with a calm & modern appearance, and most importantly, the website must contain a booking system.

# The Technical Side
At this moment there is only a front-end for this project. 
The front-end still needs a bit of work. So far there is only HTML, CSS & some JavaScript used. 
The intention is that for this project a backend will be added, mainly with the focus on the booking system. 
How this will look exactly is currently being worked out, but the expectation is to use Express for routing, Google's Calendar API for the appointments, a MongoDB or SQL database & EJS as a templating engine.
